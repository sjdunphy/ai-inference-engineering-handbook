AI Inference Engineering Handbook

This is a single-file React SPA (index.html) that renders the AI Inference Engineering Handbook  — a 31-topic guide for platform and infra engineers.

Quick Start (local):
- Open `index.html` in your browser (no build needed).
- Or run a simple static server, e.g. `python -m http.server` and open `http://localhost:8000`.

Development notes:
- The app runs in-browser using UMD builds of React and Babel standalone (JSX transformed at runtime).
- For production, consider migrating to a build system (Vite) for better performance and modular code.

Branch: `refactor/full-refactor-in-browser` contains ongoing refactor work.

See `DEPLOY.md` for GitHub Pages deployment instructions.
